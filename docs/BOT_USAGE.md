# Возможности Telegram-бота

Практическая справка по тому, что умеет Personal AI Inbox и как этим пользоваться.
Встроенная команда `/help` даёт короткую памятку; этот документ описывает
полную пользовательскую поверхность и текущие ограничения.

## Быстрый старт

Обычный сценарий максимально короткий:

```text
отправить что-нибудь боту
→ бот сохранит сообщение
→ обработает его содержимое и подготовит краткий разбор
→ бот пришлёт карточку с заголовком, выводом и действиями к источнику
```

Сообщение можно также просто переслать боту из Telegram — для поддерживаемых
типов бот сохранит доступную информацию об источнике автоматически.

Для работы Telegram user id должен входить в `ALLOWED_TELEGRAM_USER_IDS`.
Пользователи вне allowlist молча игнорируются.

## Что можно отправлять

### Обычный текст

Любое сообщение без команды и без URL сохраняется как текстовая заметка.

Пример:

```text
Разобраться, как устроены structured outputs и где они пригодятся в Android-проекте
```

После обработки по умолчанию бот показывает заголовок и короткий вывод. Категория,
тип, уровень интереса, охват анализа и следующее действие доступны по кнопке
`ℹ️ Детали`; числовой приоритет и причина ранжирования там не показываются.

### Веб-ссылки

Можно отправить одну или несколько ссылок в одном сообщении.

```text
Посмотреть применимость к нашему проекту
https://example.com/article-1
https://example.com/article-2
```

Все ссылки остаются внутри одного сохранения. Каждая ссылка обрабатывается отдельно, текст
сообщения сохраняется как пользовательский контекст, а итоговый summary строится
один раз по всему доступному содержимому. Для нескольких ссылок summary должен
учитывать содержательную часть каждой успешно разобранной ссылки, даже если темы
различаются. Если отправить один URL в разных сообщениях, это будут отдельные сохранения.

Бот скачивает только публично доступные страницы. Доступ к локальным/private
сетям блокируется. Если страницу нельзя получить безопасным способом или в ней
недостаточно текста, бот сообщит об ошибке и сохранит ссылку.

### YouTube

Ссылка на YouTube распознаётся автоматически.

```text
Посмотреть и решить, стоит ли применять
https://www.youtube.com/watch?v=...
```

Пайплайн пытается получить субтитры на настроенных языках, а если пригодных
субтитров нет — скачивает аудио и делает STT. При доступной vision-модели бот
также может извлечь representative frames и добавить визуальный контекст.

Текущие дефолтные ограничения:

- длительность YouTube — до 7200 секунд (2 часа);
- скачиваемое YouTube-аудио — до 50 MB;
- скачиваемое видео для visual analysis — до 50 MB;
- файл субтитров — до 2 MB;
- для visual analysis нужен `ffmpeg` и настроенная vision-модель.

Если анализ кадров недоступен, бот всё равно может разобрать видео по распознанной
речи. Если у видео нет звуковой дорожки или распознавание речи не дало текста,
бот попробует анализ только по кадрам; результат появится, только если анализ
кадров завершится успешно.

У готового сохранения с YouTube есть кнопка `📩 Прислать YouTube`. Она ставит отправку
исходного ролика в очередь; ролик придёт ответом на сообщение со ссылкой. Если в
одном сохранении несколько видео, у каждого будет своя кнопка. Лимит отправки
в Telegram — до 50 MB. Если видео превышает этот лимит, бот попробует отправить
только аудио и укажет это в подписи. Если аудио тоже слишком большое, бот сообщит
об этом отдельно.

### Instagram Reels

Можно отправить ссылку на конкретный Reel:

```text
https://www.instagram.com/reel/ABC123/
```

Поддерживается получение публичного видео. Доступный звук преобразуется в текст;
при включённом анализе кадров бот изучает несколько характерных кадров. Подпись
сохраняется отдельно как описание и не считается расшифровкой речи. Если речи нет
и подпись содержательна, бот может использовать её для разбора; если доступны
только кадры — разбор будет основан на них.

Лимиты по умолчанию: 2 часа и 50 MB для audio и video. Instagram может требовать
cookies или временно ограничивать доступ; бот сохранит ссылку и покажет
контролируемую ошибку. Для необязательной ручной настройки cookie file см.
[RUNBOOK](RUNBOOK.md). Stories, профили и private-account обход не поддерживаются.
У готового Reel есть отдельная кнопка `📩 Прислать Reel`; нажатие
повторно получает ролик и отправляет его ответом на сообщение со ссылкой. Лимит
отправки в Telegram — до 50 MB.
Если Reel слишком большой для отправки видео, бот попробует отправить только
аудио и прямо сообщит об этом в подписи. Если аудио тоже слишком большое, бот
сообщит об этом отдельно.

### Голосовые сообщения

Голосовое сообщение Telegram можно отправить напрямую боту. Бот скачает его,
преобразует речь в текст и проанализирует вместе с текстом и ссылками.

### Аудиофайлы

Telegram audio также поддерживается и сохраняется как `AUDIO`.

Дефолтный лимит voice/audio — 20 MB. Если файл больше, бот сохраняет метаданные,
но не скачивает файл и сообщает об ошибке размера.

Telegram video также поддерживается: бот транскрибирует звуковую дорожку и, если
модель анализа кадров доступна, добавляет сведения из нескольких кадров. Подпись и
ссылки рядом с видео анализируются в том же сохранении. Если видео не обработалось,
но есть содержательная подпись или рабочая ссылка, сохранение всё равно получит
частичный разбор. Если у видео нет звуковой дорожки, но анализ кадров успешен,
бот разберёт ролик по кадрам.

### Документы

Можно отправить или переслать PDF, TXT, Markdown (`.md`/`.markdown`) и DOCX.
Подпись и URL рядом с документом остаются в том же сохранении; для прямого сообщения
подпись также задаёт пользовательский контекст.

Из PDF извлекается выделяемый текст с сохранением порядка страниц. Сканированные
PDF и документы без извлекаемого текста завершаются понятной ошибкой: OCR не
поддерживается. Для DOCX читаются абзацы и таблицы; `.doc`, `.docm`, архивы,
таблицы и презентации не поддерживаются. Размер файла и извлечённого текста
ограничен настройками `MAX_DOCUMENT_BYTES` и `MAX_DOCUMENT_TEXT_CHARS`.

Ссылка, фактически возвращающая PDF, проходит тот же защищённый web downloader,
что и обычные страницы: проверяются публичный адрес, каждый redirect и общий
download limit. `.pdf` URL, возвращающий HTML, не считается PDF-документом.

### Пересланные сообщения

Можно пересылать боту обычный текст, статьи/YouTube-ссылки, voice, audio, video
и поддерживаемые документы.
Пересланные материалы обрабатываются так же, как отправленные напрямую.

Каждое входящее Telegram-сообщение становится одним сохранением. Несколько ссылок,
вложения и подпись, отправленные вместе, не создают отдельные записи. Бот разбирает
каждый источник, а затем готовит общий результат по всему доступному содержимому.

Если канал прислал пост как фото с подписью, бот извлекает URL из caption, включая
скрытые Telegram `text_link`, и сохраняет caption целиком как source content.
Caption анализируется даже без URL. Само изображение пока не анализируется; фото
без caption остаётся неподдерживаемым.

Если Telegram передал сведения об авторе или канале пересланного сообщения, бот их
сохраняет. Недостающие сведения он не угадывает.

Текст исходного автора не считается вашей заметкой. Он сохраняется целиком как
source content; для forwarded URL/media передаётся в анализ как source context
отдельно от `user_note`.

Для публичного канала появляется `↗ Оригинальный пост`, только если Telegram дал
и public username канала, и id исходного сообщения. Для private/hidden origin
ссылка не строится.

Результат обработки VIDEO приходит ответом на сообщение с видео. Нажмите на
заголовок ответа, чтобы вернуться к отправленному или пересланному в бот видео.
Telegram не предоставляет постоянную ссылку на отдельное сообщение в личном
чате с ботом; для публичного поста канала доступна отдельная кнопка оригинала.

### Что не поддерживается

Video note и direct image не обрабатываются. Instagram поддерживается только для
конкретных Reel URL; extraction зависит от текущего поведения yt-dlp и Instagram.
Если Telegram прислал видео как `Document` (`video/*` или распознаваемое
video-расширение), оно всё равно идёт в
VIDEO pipeline. Обычный Telegram video и forwarded video используют transcript
и optional vision. Из документов принимаются только PDF/TXT/Markdown/DOCX.

Если один из поддерживаемых вложенных sources не удалось извлечь, но у сообщения
остался текст или другой успешно обработанный источник, результат помечается как
частичный, вместо потери всего сохранения.

## Что приходит после анализа

В обычной карточке бот показывает, что именно сохранено, короткую сводку и важное
предупреждение, если часть содержимого не удалось разобрать. Категория, тип,
уровень интереса и следующий шаг доступны через `ℹ️ Детали`. Внутренняя оценка,
её числовой балл и объяснение ранжирования в карточке не показываются.

## Действия с сохранением

Основная карточка показывает кнопки источника/повторной отправки (если они есть) и
`••• Ещё`. Для нескольких источников кнопка `🔗 Источники` открывает ограниченный
список с отдельными действиями. URL-кнопки называют направление: например,
`↗ YouTube`, `↗ Instagram Reel`, `↗ GitHub`, `↗ Статья — example.com` или
`↗ Документ — example.com`.

`↩️ Оригинал` повторно присылает в чат с AIInbox сообщение, которое создало сохранение.
Это Bot API-действие, а не private Telegram permalink. У пересланного публичного
сообщения может быть и отдельная кнопка `↗ Оригинальный пост`: она открывает
публичный канал, а `↩️ Оригинал` возвращает capture из чата с ботом. Если Telegram
удалил capture, бот сообщает об этом и предлагает сохранённые source actions,
когда они доступны.

`••• Ещё` открывает действия с сохранением. Переходы по меню только показывают
доступные варианты и не меняют само сохранение.

### Сделано

`✅ Сделано` отмечает сохранение выполненным.

### Отложить

`⏰ Отложить` предлагает:

- завтра;
- через неделю;
- через месяц;
- отменить выбор.

Когда срок наступит, бот вернёт то же сохранение с заголовком, сводкой и
действиями к источнику или исходному сообщению. Тихие часы учитываются.

### Архив

`🗄 В архив` убирает сохранение из активного списка. Его можно найти через поиск.

### Интерес

Под `⭐ Интерес` доступны уровни `Низкий`, `Обычный` и `Высокий`.
Текущий уровень помечен галочкой. Выбор сохраняет существующий сигнал интереса и
не показывает и не меняет числовую оценку приоритета.

### Повторить

Если обработка не удалась или один из источников требует повторной попытки, на
карточке показывается `🔁 Повторить`. Для постоянной ошибки источника кнопки нет.

Неудачно обработанное сохранение остаётся доступно. Если анализа нет, название берётся
из уже сохранённого безопасного источника: например, `avito.ru`, `Голосовое` или
имя документа. Обычная карточка объясняет, что не удалось сделать, без внутренних
внутренних кодов ошибок; кнопка `↩️ Оригинал` и безопасные ссылки остаются доступны.

### Обратная связь и исправления

У обработанного сохранения в `🛠 Обратная связь` доступны:
`👍 Полезно`, `👎 Неинтересно`, исправление категории/типа, действия `⬆ Важнее` и
`⬇ Менее важно`, а также `📝 Неточная сводка`.

Эти действия помогают улучшать будущую сортировку и анализ. Они не отмечают
сохранение выполненным, не откладывают его и не перемещают в архив.

В меню обратной связи можно выбрать категорию или тип, сообщить, что приоритет должен
быть выше/ниже, либо отметить неверное резюме. Часто встречающиеся категории
показываются первыми и доступны через страницы; выбрать можно только уже
существующую категорию. Исправление категории сразу меняет результат /category,
а исправление типа — доступность сохранения в /today. Эти исправления не запускают
повторный анализ и не пересчитывают приоритет. После изменения карточка остаётся в
меню обратной связи; новую категорию или тип можно посмотреть в `ℹ️ Детали`.

### Детали

`ℹ️ Детали` показывает категорию, тип, уровень интереса, полноту анализа и
следующее действие, если эти сведения есть. Числовой приоритет и причину выбора
сохранения бот не показывает.

## Команды

### `/start`

Проверяет доступ, коротко подсказывает, что можно отправить, и показывает
главное inline-меню.

### `/menu`

Показывает главное inline-меню. То же меню доступно из `/start` и `/help`.
Telegram также показывает зарегистрированные команды рядом со строкой ввода.
Команды регистрируются приложением; slash-варианты остаются доступны.

### `/help`

Показывает короткую справку по задачам и кнопку главного меню.

В меню доступны Сегодня, Внимание, Сохранённое, Поиск, Спросить, На этой неделе, Категории,
Профиль, Настройки и Экспорт. Постоянная клавиатура, занимающая экран чата,
не используется.

### Поиск и «Спросить» из меню

Кнопки `🔎 Поиск` и `🧠 Спросить` предлагают отправить один текстовый запрос; под
подсказкой есть `Отмена`. Search делает локальный словесный поиск SQLite FTS5;
синонимы, перевод и транслитерация не обещаются. Ask ищет сохранённые материалы
и отвечает только на основании найденного контекста. Истории переписки между
запросами нет. Если вместо текста отправить команду, она выполнится как обычно;
forwarded-сообщения и media продолжают сохраняться как входящие материалы.

### `/today`

Показывает до трёх сохранений, к которым можно вернуться сегодня. Список не
нумеруется и не показывает числовой приоритет. Если есть следующий шаг или
оценка времени, они отображаются под конкретным названием.

Пример ответа:

```text
🎯 Сегодня

🎯 Разобрать статью про agents
Выписать применимые идеи
≈ 20 минут
```

Ручной `/today` и ежедневная подборка используют один формат, отличаются только
заголовком. Кнопки открывают конкретные сохранения из списка.

### `/attention [1-5]`

Показывает конкретные сохранения, к которым система предлагает вернуться. Без
аргумента можно выбрать, сколько карточек показать: 1, 3 или 5. Карточка содержит
название и короткую сводку, а кнопки ведут к исходному сообщению и источникам.
Жизненный цикл и обратная связь доступны через `••• Ещё`. Недавно открытые
сохранения временно реже появляются повторно.

### `/inbox` — «Сохранённое»

Показывает последние сохранения страницами. Кнопки с названиями открывают
соответствующую карточку, а `Ещё →` и `← Назад` переключают страницу. Нумерации
и общего количества нет; доступ ко всем сохранениям сохраняется.

В списке могут быть материалы, которые уже отмечены сделанными или убраны в архив.

### `/category`

Без аргумента показывает категории без счётчиков:

```text
/category
```

С аргументом показывает сохранения указанной категории:

```text
/category Обучение
```

Кнопки с названиями открывают карточки соответствующих сохранений; страницы
листаются кнопками без общего счётчика.

Категории создаются анализатором динамически, это не жёсткий enum.
Кнопка `🏷 Категории` в меню открывает тот же список категорий, что и команда.

### `/search [запрос]`

Словесный поиск по сохранённым данным через SQLite FTS5. Без аргумента бот
просит ввести запрос; явный аргумент запускает поиск сразу:

```text
/search compose recomposition
```

Поиск учитывает:

- title;
- summary;
- пользовательскую заметку;
- tags;
- извлечённый текст страницы;
- transcript, извлечённый текст документов и другой сохранённый content.

Поиск находит и ранее отмеченные либо архивированные сохранения. По умолчанию
возвращается до 10 результатов. В списке нет оценок и рангов; кнопки открывают
карточки в порядке поиска. Поиск не переводит слова и не расширяет их синонимами:
например, `Андроид` может не найти материал с `Android`. При пустой выдаче бот
объясняет это ограничение и предлагает начать новый поиск.

### `/ask <вопрос>`

Синтезирует ответ только по уже сохранённым материалам, которые нашёл поиск.
Без аргумента команда просит ввести вопрос; явный вопрос запускается сразу:

```text
/ask Какие варианты локальных LLM на Android я сохранял?
```

Ответ не обещает найти материал, который FTS5 не выдал. Бот сразу подтверждает
запрос, затем присылает один ответ с источниками и
кнопками открытия, если у источника есть сохранённый HTTP(S) URL. Ответ строится
в языке из `/profile`; исходный текст не переводится и внешние страницы не
обновляются. Если поиск не находит сохранений, LLM не вызывается. Если найденных
сведений недостаточно, бот прямо сообщает об этом вместо неподтверждённого
ответа. У подтверждённой цитаты также может быть `↩️ Оригинал`. Для ответа,
собранного из нескольких источников, URL-кнопка показывается только при единственном
сохранённом адресе. Каждый `/ask` — отдельный вопрос без истории переписки.

Пределы: вопрос — 2000 символов; поиск — до 8 сохранений по умолчанию, максимум 10;
контекст — не более 6000 символов на материал и 40000 суммарно. `/ask` использует
ту же языковую модель, что и анализ сохранений.

### `/export [compact|full]`

Без аргумента показывает выбор Compact или Full; выбранный вариант отправляет
переносимую копию сохранённых данных одним ZIP-файлом. Явный режим запускает
соответствующий экспорт напрямую:

```text
/export
/export compact
/export full
```

Бот быстро подтверждает запрос и готовит архив в фоне. `compact` содержит
сохранения, сведения об источниках, профиль, настройки и историю напоминаний
без длинного сохранённого текста и транскриптов. `full` дополнительно
включает исходный текст, тексты страниц и документов, транскрипты, визуальные
заметки и описания. Полный экспорт может содержать приватные сохранённые тексты и
транскрипты.

Экспорт включает все сохранения, в том числе выполненные, архивные и неудачно
обработанные. Это переносимый пользовательский формат, а не
SQLite backup и не способ импортировать данные обратно. Архив отправляется через
Telegram; если полный ZIP превышает лимит отправки, бот сообщит об ошибке и
предложит `/export compact`.

Кнопка `📦 Экспорт` в главном меню и команда без аргумента показывают тот же
выбор. Повторный callback одного сообщения не создаёт второй ExportJob.

### `/profile`

Показывает профиль пользователя, который может содержать профессию, домены,
цели с весами, интересы, ограничения, язык ответа и свободные заметки. Кнопка
`✏️ Настроить профиль` принимает одну инструкцию и передаёт её на фоновое
обновление. Сама инструкция не сохраняется как отдельный материал.

Профиль учитывается при анализе новых сохранений.

### `/profile_update [инструкция]`

Обновляет профиль естественным языком в фоне. Без аргумента бот просит отправить
инструкцию отдельным сообщением; текст не сохраняется как материал.

```text
/profile_update Сейчас хочу повысить приоритет изучения AI-агентов и меньше внимания уделять Kubernetes
```

Команда быстро отвечает `Принял. Обновляю профиль…`; после завершения бот уведомит
об изменённых полях.

Изменение профиля не запускает повторный анализ уже сохранённых материалов.
Язык ответа для видео можно установить командой
`/profile_update отвечай по-английски`; в `/profile` он показывается кодом,
например `en`. Transcript может быть на другом языке, но итоговые title, summary,
следующее действие и описание кадров будут на языке профиля. Для остальных
источников сохраняется текущий выбор языка по языку контента.

### `/settings`

Показывает настройки уведомлений на русском языке: часовой пояс, локальное время,
ежедневную подборку, тихие часы, состояние функции «Внимание» и её интенсивность.
Кнопки изменения запрашивают одно значение и сохраняют его после проверки.

При первом использовании дефолты такие:

```text
ежедневная подборка: включена
время: 09:00
тихие часы: 22:30-08:00
```

Отдельная кнопка `📊 Статус` открывает служебную диагностику: там видны лимиты,
подходящие материалы и причины, которые сейчас задерживают отправку. Обычные
настройки эти счётчики не показывают. Экран статуса только читает данные и не
ставит напоминания в очередь.

Изменить timezone:

```text
/settings timezone Europe/Moscow
```

Изменить время ежедневной подборки:

```text
/settings time 09:00
```

Изменить quiet hours:

```text
/settings quiet 22:30-08:00
```

Открыть настройки функции «Внимание»:

```text
/settings attention
```

В меню настроек есть кнопка `✨ Внимание`; с её экрана можно вернуться к основным
настройкам.

Интенсивность называется: `1 — Спокойно`, `2 — Легко`, `3 — Обычно`, `4 — Активно`,
`5 — Очень активно`. Новые пользователи получают функцию включённой в обычном
режиме. Для пользователей, существовавших до PM-08, она выключена после
обновления; включить её можно кнопкой в `/settings attention`.

Настройка `Дополнительные напоминания` включает или выключает мотивационные
уведомления. Для новых пользователей она включена; у существовавших пользователей
после обновления остаётся выключенной, если значение не было задано раньше.
Отключение этой настройки не выключает отдельную функцию «Внимание».

В явно открытом статусе показываются служебные правила частоты. Они не появляются
в обычном экране настроек:

| Уровень | Режим | Общий дневной предел | Интервал | Повтор материала |
|---:|---|---:|---:|---:|
| 1 | Спокойно | 1 | 8 ч | 72 ч |
| 2 | Легко | 2 | 5 ч | 48 ч |
| 3 | Обычно | 3 | 3 ч | 30 ч |
| 4 | Активно | 4 | 2 ч | 20 ч |
| 5 | Очень активно | 6 | 90 мин | 12 ч |

Общий предел включает ежедневную подборку, напоминания о конкретных сохранениях
и дополнительные мотивационные сообщения. Дополнительные сообщения имеют свой
дневной предел; отложенные материалы не расходуют общий предел, но влияют на
интервал между отправками. Все автоматические сообщения учитывают тихие часы.
Изменение этих правил не меняет порядок ранжирования сохранений.

Дополнительное напоминание всегда показывает конкретное сохранение: его название
и сохранённую сводку. Причина выбора и агрегированные факты не выводятся. Если
подходящего сохранения нет, сообщение не отправляется. Текст берётся из уже
сохранённого материала; LLM для этих сообщений не вызывается. `👎 Меньше таких`
на время отключает этот вид напоминаний, не меняя остальные настройки.

Timezone должен быть валидным IANA timezone, время задаётся в формате `HH:MM`.

## Уведомления

### Результат обработки

После обработки бот присылает результат. Если обработка завершилась ошибкой,
приходит короткое объяснение и кнопка `🔁 Повторить`, когда повтор возможен.
Сообщение отвечает на исходный текст, ссылку или медиа, если Telegram-сообщение
доступно.

Immediate notifications проходят через durable outbox: намерение отправить
сообщение хранится в SQLite и переживает restart процесса.

### Ежедневная подборка

Если ежедневная подборка включена, бот один раз в день показывает несколько
конкретных сохранений через ту же логику, что `/today`. Время задаётся командой
`/settings time ...`.

Подборка не отправляется в тихие часы. У каждого материала есть кнопка, которая
открывает его карточку.

### Напоминание об отложенном сохранении

`⏰ Отложить` предлагает выбрать срок. Когда он наступит, бот пишет
`⏰ Вы хотели вернуться к этому` и показывает название, сводку и действия к
источнику. Тихие часы учитываются.

### Внимание

Когда функция «Внимание» включена, бот может прислать одно конкретное сохранение
с заголовком и содержательной сводкой или подтверждённым фрагментом. Рейтинг,
интерес, возраст материала и причина выбора пользователю не показываются.

Кнопки возвращают к исходному сообщению и источникам. Через `••• Ещё` доступны
`⏰ Отложить`, `✅ Сделано`, `🙈 Не сейчас` и `👎 Меньше таких`. Одно и то же
сохранение можно открыть, отложить, отметить сделанным или убрать в архив.

`↩️ Оригинал` возвращает исходное сообщение. Ссылки ведут к сохранённым
источникам; переходы по обычным URL-кнопкам не создают дополнительного действия
в боте.

Сводка для напоминания берётся из уже сохранённого материала; при её отсутствии
бот показывает только название. Дополнительные мотивационные напоминания
используют тот же формат, обязательно относятся к существующему сохранению и не
создают текст моделью.

`Не сейчас` откладывает автоматический повтор. `Меньше таких` временно подавляет
этот вид дополнительных напоминаний. Эти кнопки не меняют категорию, интерес или
числовую оценку материала.

## Типичные сценарии

### Быстро сохранить мысль

```text
Сделать прототип локального semantic search для заметок
```

Ничего классифицировать вручную не нужно.

### Сохранить статью с контекстом

```text
Проверить, можно ли применить этот подход в PhotoSearch
https://example.com/article
```

Заметка сохранится вместе со ссылкой и будет участвовать в анализе и поиске.

### Разобрать несколько ссылок

```text
Сравнить подходы
https://example.com/a
https://example.com/b
https://example.com/c
```

Получится одно сохранение: бот обработает все три страницы и сделает общий разбор.
В итоговом title/summary должны быть представлены все три содержательные части,
а не только первая ссылка.

### Надиктовать задачу

Отправить voice message вместо текста. Бот транскрибирует его и обработает как
обычный входящий материал.

### Сохранить длинное YouTube-видео

Прислать ссылку на YouTube. Бот постарается использовать subtitles, иначе STT,
а при настроенном vision — добавит visual context.

### Выбрать, чем заняться сейчас

```text
/today
```

После выполнения нажать `✅ Сделано`, либо `⏰ Отложить`, если к сохранению нужно
вернуться позже.

Для динамического списка с учётом возраста, интереса и предыдущих показов:

```text
/attention
```

### Посмотреть, как прошла неделя

```text
/weekly
```

Команда отвечает на вопрос: к каким сохранениям сейчас имеет смысл вернуться?
Она показывает до трёх конкретных материалов и короткое объяснение следующего
шага. Если рекомендаций нет, бот сообщает, что на этой неделе пока нечего отдельно
возвращать в фокус. Статистика добавлений, выполнения, архивов и напоминаний не
показывается. Команда остаётся только для чтения и не меняет сохранения или
настройки.

### Найти старый материал

```text
/search structured outputs android
```

Поиск работает и по содержимому сохранённых страниц и расшифровок, а не только по
названию материала.

### Сопоставить сохранённые материалы

```text
/ask Сравни подходы к локальным LLM на Android, которые я сохранял
```

Ответ составляется по найденным материалам и показывает названия источников.
`/ask` не ищет в интернете и не сохраняет ответ как новый материал.

### Изменить приоритеты системы

```text
/profile_update В ближайшие месяцы главный фокус — AI agents, Android ML и backend
```

Следующие сохранения будут анализироваться с учётом обновлённого профиля.

## Важные ограничения

- доступ к боту ограничен Telegram allowlist;
- direct/forwarded Telegram video поддерживаются, включая video-as-document;
- direct image и video note пока не обрабатываются;
- документы ограничены PDF/TXT/Markdown/DOCX и настройками file/text size;
- OCR, `.doc`/`.docm`, таблицы, презентации и произвольные архивы не поддерживаются;
- web extraction ограничен публичной сетью и download cap 5 MB;
- URL PDF использует тот же web download cap 5 MB и SSRF-защиту;
- voice/audio ограничены 20 MB по умолчанию;
- YouTube ограничен 2 часами и media caps из конфигурации;
- Instagram Reel ограничен `INSTAGRAM_MAX_DURATION_SECONDS` и отдельными audio/video caps;
- для OpenRouter long-audio STT и video visual analysis нужен `ffmpeg`;
- без vision-модели YouTube/Telegram video всё равно обрабатываются по transcript;
- вывод Telegram ограничивается 4096 символами, поэтому длинные ответы
  автоматически обрезаются;
- `/inbox` показывает последние сохранения, включая отложенные, выполненные и архивные;
- профиль влияет на будущие анализы, но не пересчитывает старые сохранения;
- semantic/vector search в MVP нет — `/search` использует SQLite FTS5.
- `/ask` ищет слова в сохранённых материалах; он не обновляет источники,
  не ищет по смысловым сходствам и не ведёт историю вопросов.

## Если что-то упало

Если сохранение не обработалось, нажмите `🔁 Повторить`. Система сохраняет
промежуточные результаты и старается продолжить с уже выполненного этапа.

Для технической диагностики приложения и базы данных откройте
[RUNBOOK](RUNBOOK.md). Эта страница описывает пользовательскую поверхность
Telegram-бота.
